# Arya Gupta's portfolio

A plain HTML portfolio hosted on Cloudflare.

[aryabuilds.online](https://aryabuilds.online/)

## Edit and preview

Edit `public/index.html` and open it in a browser.

## Deploy

Run from the project directory:

```sh
npx wrangler@latest login
npx wrangler@latest deploy
```

Hosting settings are in `wrangler.jsonc`.
